================================================================================
          HƯỚNG DẪN CÀI ĐẶT VÀ SỬ DỤNG TOOL AUTO MICROSOFT REWARDS (4+ ACC)
================================================================================

Tool này giúp bạn tự động tìm kiếm trên Microsoft Edge hàng ngày để ăn trọn điểm thưởng
Microsoft Rewards cho 4 tài khoản (hoặc nhiều hơn) cả Desktop (PC) và Điện thoại Mobile.
Đã tích hợp cơ chế chống ban (gõ phím từng ký tự, cuộn trang đọc bài, nghỉ ngẫu nhiên).

--------------------------------------------------------------------------------
CÁCH 1: DÙNG GIAO DIỆN WEB UI HIỆN ĐẠI (KHUYÊN DÙNG - CỰC KỲ DỄ DÙNG)
--------------------------------------------------------------------------------
1. Bạn chỉ cần nhấp đúp chuột vào file: [start_web_ui.bat]
   - Bảng đen sẽ tự động kiểm tra và khởi động Web Server.
   - Trình duyệt sẽ tự động mở trang quản lý tại: http://127.0.0.1:5000

2. Đăng nhập lần đầu cho 4 tài khoản (Chỉ cần làm 1 lần duy nhất):
   - Trên giao diện Web, bạn sẽ thấy 4 Card tương ứng với 4 Tài khoản:
     • Profile 1 (Acc 1)
     • Profile 2 (Acc 2)
     • Profile 3 (Acc 3)
     • Profile 4 (Acc 4)
   - Bấm nút [🔑 Đăng Nhập Edge] tại Card của từng tài khoản:
     + Trình duyệt Edge sẽ mở ra trang Microsoft Rewards.
     + Bạn đăng nhập tài khoản Microsoft tương ứng.
     + Đăng nhập xong thì đóng cửa sổ Edge lại.
     + Phiên đăng nhập sẽ được lưu vĩnh viễn trong thư mục riêng của từng acc!

3. Cày điểm hàng ngày (Thao tác 1-Click):
   - Bấm nút lớn màu xanh: [🚀 CHẠY TẤT CẢ 4 ACC (FULL PC + MOB)]
   - Bot sẽ tự động chạy lần lượt qua Acc 1 -> Nghỉ an toàn -> Acc 2 -> Acc 3 -> Acc 4.
   - Màn hình Live Terminal bên phải hiển thị trực tiếp từng bước, từ khóa, và số điểm kiếm được.
   - Khi cần dừng lại: Bấm nút đỏ [🛑 DỪNG KHẨN CẤP].

4. Các chức năng nâng cao khác trên Web UI:
   - Chạy riêng lẻ: Bấm nút [PC], [Mobile] hoặc [Full] trên từng Card tài khoản.
   - Thêm tài khoản mới: Bấm [+ Thêm Tài Khoản] để thêm Acc 5, Acc 6...
   - Cài đặt tìm kiếm: Bấm nút [Cấu hình] để chỉnh số lượt PC (31), Mobile (21), thời gian delay, chế độ ẩn danh (Headless).
   - Kho từ khóa: Bấm nút [Từ khóa] để thêm bớt hoặc bổ sung từ khóa tìm kiếm tự nhiên.

--------------------------------------------------------------------------------
CÁCH 2: CHẠY BẰNG BẢNG ĐEN (CMD / BAT TRUYỀN THỐNG)
--------------------------------------------------------------------------------
Nếu bạn không muốn mở trình duyệt quản lý, bạn vẫn có thể chạy các file .bat có sẵn:
- [run_bot.bat]    : Menu chọn 1 trong 4 Profile hoặc Chạy cả 4 (chọn chế độ PC/Mobile/Cả hai).
- [run_pc.bat]     : Menu chọn nhanh chế độ Desktop (PC).
- [run_mobile.bat] : Menu chọn nhanh chế độ Mobile (Điện thoại).

--------------------------------------------------------------------------------
CẤU TRÚC THƯ MỤC PROFILE RIÊNG BIỆT:
--------------------------------------------------------------------------------
- Profile 1 -> thư mục: edge_profile
- Profile 2 -> thư mục: edge_profile_2
- Profile 3 -> thư mục: edge_profile_3
- Profile 4 -> thư mục: edge_profile_4
Mỗi tài khoản hoàn toàn độc lập, không sợ bị ghi đè cookie hay văng session!
